#### G5-6 英文门禁边界（冻结）

- `english_policy.py` 是**无新增依赖的保守保存前门禁**，只在 ASCII Latin、最少两个 token、无明确法/西语/占位标记、可读元音形态及已知词覆盖同时成立时返回 `en`；它不是翻译器、通用 NLP 或任意领域语言识别证明。
- HTML/JSON 自然语言值只抽取文本叶子后判定；Schema 标为非自然语言的数字、枚举、标识符不走本门禁。任何混合脚本、中文、未知词比例超限、不可读乱码或证据不足均返回 `UNKNOWN`，预览/冻结 fail-closed，后续不得点击保存。
- 扩充词表必须同时提供目标类目正常标题和对抗伪词/非英文回归；不得为提高召回率降低 unknown 阈值，也不得在未授权时下载模型或引入运行时网络依赖。

#### G5-8 data lease 与测试隔离（冻结）

- live backend、桌面进程与 pytest 不得共享同一个可写 `DXM_DATA_DIR`；完整/聚焦 pytest 必须在服务停止后运行，或为该次命令设置唯一的隔离目录。
- 隔离目录不得复制 `data/sessions`、Cookie、raw 抓包或真实业务样例；测试结束前不得把隔离数据解释成真实店小秘证据。
- 完整 L0 的正式证据必须记录实际 `DXM_DATA_DIR`、命令、exit code、passed/failed/skipped；`-x` 只用于定位首失败，不能替代完整门禁。
