# DXM Agent Console 免安装版 · 一页说明

> 由 OpenAI GPT（Codex）AI 生成/维护。

> 当前版本以 `app/desktop/package.json` 的 `version` 为准。没有对应 `DXM-Agent-Console-Portable-<version>.exe` 时，不得把源码网页或旧 `0.1.0` 包当作正式入口。

1. 双击 `DXM-Agent-Console-Portable-<version>.exe`。不要打开 PowerShell，也不要访问 `localhost`。
2. 首次启动会在 `%APPDATA%\DXM Agent Console\data` 写入数据与 `desktop-main.log`。启动失败也先看这个日志。
3. 在中文控制台登录店小秘，选择真实店铺、类目和草稿商品。
4. 为每个类目选择店小秘已有的属性 / 运费 / 服务模板；控制台用中文映射，写入店小秘的自然语言必须是英文。
5. 先预览再冻结。每一步会出现在「保存结果」页的操作时间线。
6. 出问题可导出脱敏诊断 ZIP。密码、Cookie、token 不会进入日志或压缩包。
7. 真实只保存必须另一次明确批准。任何 `UNKNOWN` 会停批，不会自动再点。
