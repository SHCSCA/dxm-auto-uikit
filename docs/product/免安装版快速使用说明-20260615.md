## 适用范围

此免安装版用于真实店小秘半托管自动化的受控两段式流程：先从数据采集认领商品到采集箱，再从采集箱进入编辑页补齐配置并执行单商品只保存。

当前只放行数据采集认领和受控单商品只保存。批量、无人值守和发布入口仍保持关闭。

## 启动

1. 首选双击当前免安装 EXE：`D:\Desktop\DXM-Agent-Console-免安装版\DXM-Agent-Console-Portable-0.1.0.exe`。
2. 如果从仓库运行，优先使用 `outputs\desktop-build\DXM-Agent-Console-Portable-0.1.0.exe`；需要目录版时使用 `outputs\desktop-build\win-unpacked\DXM-Agent-Console.exe`。
3. 首次启动会启动本机 Python 后端和前端资源；等待工作台出现“继续下一步”。

不要单独启动后端或前端窗口。桌面版会在一个 Agent 控制台窗口内管理本机服务。

使用目录版时必须保留整个文件夹和 `resources` 目录，不能只复制 exe 文件。当前给用户的 D 盘目录是单文件 portable，不需要旁边保留 `resources`。

单文件 portable 也可用于分发：

```text

```

portable 首次启动会解包 Electron 与 Python 运行时，`%TEMP%` 所在磁盘至少建议保留 1GB 可用空间；空间不足时可能启动即退出且不生成日志。真实用户优先使用目录免安装版。

## 推荐操作顺序

1. 进入“操作首页”。
2. 按“现在只做这一步”完成真实店小秘登录。
3. 进入“数据采集认领”，选择真实店铺，创建采集认领任务。
4. 到“执行浏览器”启动第一段 Agent，只把商品从数据采集认领到采集箱，不保存、不发布。
5. 进入“采集箱编辑保存”，选择刚认领进入采集箱的商品。
6. 进入“模板中心”，按店小秘编辑页分区填写或套用本次任务的真实取值。
7. 运行真实只读检查。检查未通过时不要启动保存。
8. 人工确认后启动单商品只保存。
9. 进入“执行浏览器”观察真实浏览器、实时日志和当前步骤。
10. 完成后进入“结果与问题”核对保存成功、未发布证明和网络保存回包。

## 关键边界

- 可以做：真实登录、数据采集认领、采集箱编辑配置、真实只读检查、受控单商品只保存、报告复核。
- 不可以做：批量保存、无人值守写入、发布、保存并发布、移入待发布。
- 如果页面提示当前任务不存在，请先到“数据采集认领”重新创建认领任务；认领成功后再到“采集箱编辑保存”创建单商品只保存任务。
- 如果提示工作台服务异常，请先看“真实浏览器”的运行日志。

## 登录状态异常处理

如果真实店小秘浏览器已经显示已登录，但工作台仍显示“登录未通过”或“浏览器连接异常”，先确认正在使用 2026-06-22 之后的免安装版。该版本会优先复用可见登录浏览器的已登录状态，避免在同一 Playwright 会话中再次启动同步探针造成误报。

处理顺序：

1. 保持真实店小秘浏览器窗口打开。
2. 在“账号登录”点击“验证码完成后检测登录状态”。
3. 如果仍失败，查看“查看状态详情”里的真实错误；不要重复创建保存任务。
4. 必要时关闭当前 DXM-Agent-Console.exe 和残留浏览器窗口，再从 `D:\Desktop\DXM-Agent-Console-免安装版\DXM-Agent-Console-Portable-0.1.0.exe` 重新打开。
