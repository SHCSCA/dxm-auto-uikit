## 2. 产品结论

当前阶段不应继续扩大人工模拟操作范围，也不应把系统做成“AI 临场点页面”。真正可批量、可控、可复盘的方向，是把流程做成“配置驱动 + 状态机执行 + 异常池兜底 + 只保存不发布”。

V1.0 的目标不是全自动发布，而是将采集箱商品补齐到可人工复核的待发布状态。系统目标能力包括领取、备注、编辑普通商品信息、勾选半托管、填写半托管信息、保存、校验、报告生成；当前真实执行只能在 L2/L3 门禁和人工批准下以受控 save-only 模式逐步放行。

最终产品方向：

```text
字段先建模
模板先配置
页面按状态机执行
每步可校验
失败可追溯
发布强隔离
保存可闭环
```

## 3. 一句话定位

店小秘速卖通半托管自动化执行器，是一个本地运行的、配置驱动的、状态机式商品保存工具。它通过真实浏览器操作店小秘页面，把采集箱商品按照运营配置补齐字段，并保存到待发布。

它不是：

- 不是 AI 随机点页面。
- 不是一次性脚本。
- 不是无脑批量发布工具。
- 不是替代店小秘的 ERP。
- 不是验证码破解工具。

它是：

- 自动领取、备注、编辑字段。
- 自动填写普通商品信息。
- 自动进入半托管编辑页。
- 自动填写半托管信息。
- 自动保存到待发布。
- 自动记录截图、DOM、接口返回和执行报告。
- 遇到风险自动停止并进入异常池。

## 4. 产品目标

### 4.1 业务目标

把运营人工处理一条速卖通半托管商品的流程，抽象成可配置、可复用、可审计、可批量执行的系统流程。

核心目标：

- 降低重复填表时间。
- 避免误操作非任务商品。
- 避免误发布。
- 让运营助理可以按模板批量处理商品。
- 让主管可以通过报告复核执行结果。
- 为后续全托管、多类目、多店铺扩展打基础。

### 4.2 产品成功标准

V1.0 成功标准：

- 能进入速卖通采集箱。
- 能定位目标商品。
- 能写入领取标记，例如 AI认领。
- 能确认只操作自己领取的商品。
- 能进入普通商品编辑页。
- 能填写标题、类目、属性、SKU、价格、库存、物流、图片、合规字段。
- 能勾选半托管服务。
- 能进入半托管编辑页。
- 能填写国家、是否原箱、物流属性、重量尺寸、SKU、货品编码、货品条码策略、JIT 库存。
- 能点击保存并读取成功提示。
- 全流程不点击发布按钮。
- 失败时进入异常池。
- 每个商品生成执行报告。

## 5. 产品范围

### 5.1 V1.0 必做范围

V1.0 只做速卖通半托管保存闭环。

```text
登录态检查
→ 进入速卖通采集箱
→ 筛选店铺和商品
→ 添加领取备注
→ 进入普通编辑页
→ 填写普通商品信息
→ 勾选半托管参与
→ 进入半托管编辑页
→ 填写半托管信息
→ 保存
→ 校验保存成功
→ 生成报告
```

### 5.2 V1.0 不做范围

V1.0 不做：

- 不自动发布。
- 不立即发布。
- 不继续发布。
- 不保存并发布。
- 不自动绕过验证码。
- 不伪造品牌授权、欧盟责任人、制造商、CE、MSDS、UPC、EAN、GTIN。
- 不支持 Shopee、Lazada、Amazon、Temu 等平台。
- 不做全托管正式执行。
- 不做云端代登录。
- 不做多人审批流。

### 5.3 V1.1 后续范围

V1.1 再考虑：

- 全托管独立流程。
- 多类目模板。
- 多店铺批量。
- 图片银行完整目录选择。
- 保存后回到待发布列表校验。
- 异常池一键重试。
- 批量断点续跑。
- Excel / CSV 商品导入。

## 6. 用户角色

### 6.1 运营主管

运营主管负责配置和复核：

- 配置店铺。
- 配置类目模板。
- 配置价格、库存、物流规则。
- 审核异常池。
- 查看执行报告。
- 决定是否人工发布。

### 6.2 运营助理

运营助理负责执行和处理异常：

- 导入商品。
- 创建任务。
- 启动自动化。
- 处理失败商品。
- 在验证码或页面异常时人工接管。

### 6.3 系统执行器

系统执行器负责确定性动作：

- 按配置操作真实店小秘页面。
- 读取 DOM 和接口返回。
- 保存截图、DOM 快照、网络日志。
- 遇到风险立即停止。
- 生成报告。

## 7. 核心原则

### 7.1 配置优先

系统运行前必须配置完整。执行过程中不允许临场猜测关键字段。

必须预先配置：

- 店铺。
- 商品范围。
- 类目模板。
- 标题规则。
- SKU 规则。
- 价格规则。
- 图片规则。
- 物流模板。
- 合规模板。
- 半托管模板。
- 异常处理策略。

### 7.2 商品归属锁

执行器只能操作明确属于当前任务的商品。

归属判断条件：

- 商品来自当前任务队列。
- 商品行已写入当前任务领取标记。
- 编辑页中的店铺、标题、SKU、商品 ID 与任务 payload 一致。

不满足归属条件时，必须停止，不能继续编辑。

### 7.3 发布强隔离

默认模式下，只允许点击：

- 保存。
- 提交。
- 编辑半托管信息。
- 明确属于非发布动作的确认按钮。

禁止点击：

- 立即发布。
- 发布。
- 继续发布。
- 保存并发布。
- 任何含义不明且可能触发发布的按钮。

如果出现发布确认或风险确认，立即停止。

### 7.4 字段真实性

系统可以自动生成：

- 标题。
- SKU。
- 货品编码。
- 商品编码。
- 描述。
- 库存。
- 价格。
- 货值。

系统不能无依据伪造：

- 品牌授权。
- IP 授权。
- 专利供应。
- 欧盟责任人。
- 制造商真实信息。
- MSDS / CE / 电池证书。
- UPC / EAN / GTIN。

## 8. 系统总体结构

V1.0 产品由 7 个核心模块组成：

```text
1. 配置中心
2. 任务中心
3. 执行控制台
4. 店小秘页面执行器
5. 证据中心
6. 异常池
7. 执行报告
```

系统运行链路：

```text
用户配置任务
→ 系统启动前校验
→ Playwright 控制真实浏览器
→ 页面适配器按状态机执行
→ 每一步写入证据
→ 成功保存到待发布
→ 失败进入异常池
→ 生成报告
```

## 9. 模块一：配置中心

### 9.1 模块目标

配置中心是系统核心。不是执行器先动手，而是配置中心先定义“该怎么做”。

配置中心至少包括：

- 店铺配置。
- 任务配置。
- 类目模板。
- 标题模板。
- SKU 与编码规则。
- 价格库存规则。
- 包装物流模板。
- 图片规则。
- 合规模板。
- 半托管模板。
- 发布禁用规则。
- 异常处理策略。

### 9.2 店铺配置

| 字段 | 示例 |
|---|---|
| 平台 | 速卖通 |
| 店铺名称 | Dang Kang |
| 匹配方式 | 精确匹配 |
| 登录态策略 | 本地浏览器 |
| 会话失效 | 停止并进异常池 |

规则：

- 不保存店小秘账号密码。
- 用户在真实页面登录。
- 登录失效时停止执行。

### 9.3 任务配置

| 字段 | 默认值 |
|---|---|
| 商品来源 | 采集箱 |
| 领取标记 | AI认领 |
| 备注颜色 | 红色 |
| 执行模式 | 只保存 |
| 是否允许发布 | 否 |

任务配置还应包含最大处理数量、店铺筛选、商品分组、商品关键词、类目模板、价格规则、物流模板、图片规则和半托管模板。

### 9.4 类目模板

类目模板用于固定类目和属性默认值。

| 字段 | 示例 |
|---|---|
| 类目名 | 立牌类谷子 |
| 英文名 | ACG Stand |
| 默认品牌 | None |
| 材质 | Other |
| 是否定制 | No |

同一分类应复用一套默认属性模板。单商品只覆盖差异字段。

### 9.5 标题与文案模板

标题配置包括：

- 标题来源。
- 标题语言。
- 标题模板。
- 禁词表。
- 侵权词表。
- 长度限制。
- PC 详情模板。
- 无线详情模板。

标题生成策略：

```text
类目词 + 动漫周边词 + 产品形态词 + 场景词 + 礼品词
```

保存前校验：

- 不为空。
- 不超长。
- 不含中文。
- 不含禁词。
- 不含高风险品牌词。

### 9.6 SKU 与编码规则

SKU 策略支持：

1. 沿用店小秘生成。
2. 用户自定义规则。
3. 系统预设规则。

默认建议：

- SKU 沿用店小秘。
- 货品编码默认等于 SKU。
- 货品条码默认留空。
- SKU 重复时按配置自动修正或停止。

### 9.7 价格与库存规则

| 字段 | 默认策略 |
|---|---|
| 零售价 | 沿用店小秘 |
| 货值 | 固定为 1 |
| 普通库存 | 200 |
| JIT 库存 | 100 |
| 价格为空 | 进异常池 |

### 9.8 包装与物流模板

默认模板建议：

| 字段 | 示例 |
|---|---|
| 重量 | 0.03kg |
| 长宽高 | 10 x 10 x 2cm |
| 是否原箱 | 否 |
| 物流属性 | 普货 |

### 9.9 图片配置

图片来源应按优先级配置，不能运行时随机猜。

图片类型：

- 主图。
- 白底图。
- 场景图。
- 详情图。
- 欧盟产品本体标签图。
- 欧盟外包装标签图。

图片选择规则：

- 指定图片 ID。
- 指定目录。
- 指定标签。
- 指定文件名关键词。
- 最新一张。
- 第一张可用图。

### 9.10 合规模板

合规模板字段：

- 欧盟负责人。
- 制造商。
- 海关属性。
- Tax code。
- 产品本体标签图。
- 外包装标签图。
- 特殊资质。

原则：

- 无真实配置不自动填。
- 缺少必填合规字段进入异常池。
- 不伪造资质。

### 9.11 半托管模板

| 字段 | 默认值 |
|---|---|
| 参与半托管 | 是 |
| 参加国家 | 全选 |
| 是否原箱 | 否 |
| 物流属性 | 普货 |
| 重量尺寸 | 沿用普通页 |
| 货品编码 | 等于 SKU |
| 货品条码 | 留空 |
| JIT 库存 | 100 |

### 10.2 任务状态

queued

paused

failed

### 10.3 创建任务流程

用户创建任务时：

3. 设置筛选条件。

10. 选择合规模板。
11. 选择半托管模板。

## 12. 模块四：店小秘页面执行器

### 12.1 执行器原则

执行器必须：

- 用 DOM 定位主操作。
- 用 URL 和页面标题判断页面状态。
- 用表单 label 定位字段。
- 用表头 + 行名定位变种表格。
- 用网络接口返回校验保存。
- 用截图记录证据。
- 不使用写死坐标作为主方案。

### 12.2 状态机

V1.0 状态机：

```text
INIT
→ CHECK_LOGIN
→ OPEN_DRAFT_LIST
→ FIND_PRODUCT
→ CLAIM_PRODUCT
→ OPEN_EDIT_PAGE
→ FILL_BASE_INFO
→ FILL_VARIANTS
→ FILL_MEDIA
→ FILL_COMPLIANCE
→ ENABLE_SEMI_MANAGED
→ OPEN_SEMI_MANAGED_PAGE
→ FILL_SEMI_GOODS
→ FILL_SEMI_VARIANTS
→ SAVE_ONLY
→ VERIFY_RESULT
→ DONE
```

失败状态：

```text
FAILED
→ CAPTURE_EVIDENCE
→ WRITE_EXCEPTION
→ STOP_OR_NEXT_PRODUCT
```

## 13. 核心业务流程

### 13.1 阶段 A：登录态检查

目标：确认真实浏览器已登录，关闭非业务弹窗。

步骤：

1. 打开店小秘。
2. 检查主导航是否可见。
3. 检查是否跳登录页。
4. 检查公告、培训、产品动态弹窗。
5. 关闭可关闭弹窗。
6. 记录登录态截图。

成功条件：主导航可见，无遮挡弹窗，当前账号可操作。

### 13.2 阶段 B：进入采集箱

目标：进入速卖通采集箱，并按店铺和任务条件筛选目标商品。

路径：

```text
产品 → 数据采集 / 速卖通 → 采集箱
```

也可直接打开：

```text
/web/smt/smtProductList/draft
```

### 13.3 阶段 C：领取与备注

目标：给目标商品写入领取标记，让后续操作只锁定自己领取的商品。

步骤：

1. 定位商品行。
2. 点击更多。
3. 点击添加备注。
4. 写入领取标记。
5. 选择备注颜色。
6. 提交。
7. 校验行内出现备注。

默认领取标记：AI认领。

### 13.4 阶段 D：进入普通商品编辑页

目标：打开编辑页，并再次校验商品归属。

步骤：

1. 点击行级编辑。
2. 等待页面加载。
3. 读取标题、店铺、商品 ID、SKU。
4. 与任务 payload 比对。
5. 保存初始截图和 DOM。

不一致时立即停止，进入异常池，不做任何字段编辑。

### 13.5 阶段 E：填写类目

目标：选择或确认目标类目，并等待属性区域刷新。

步骤：

1. 读取当前类目。
2. 不一致时按模板重新选择。
3. 校验类目路径。
4. 等待属性加载。

### 13.6 阶段 F：填写标题与基础属性

目标：按配置写入英文标题，并填写必要基础属性。

字段：

- 标题。
- 品牌。
- 材质。
- 尺寸。
- 是否 IP 授权。
- 是否定制。
- 是否礼物。
- 是否专利供应。

规则：标题不能含中文，不能含禁词；无真实依据字段只能填模板默认值；缺少必填属性则停止。

### 13.7 阶段 G：填写变种信息

目标：填写 SKU、价格、库存、重量、尺寸、是否原箱、物流属性、商品编码。

定位规则：

```text
表头列名 + 行变种名
```

禁止直接用“第几个 input”。

成功条件：变种行数与任务配置一致，SKU 唯一，商品编码唯一，物流属性符合配置，必填项无空值。

### 13.8 阶段 H：选择模板

目标：选择运费模板、服务模板、详情模板、合规模板。

失败时：模板不存在则停止，不能自动新建店小秘模板，写入异常池。

### 13.9 阶段 I：处理图片

目标：补齐图片槽位，并校验图片已回填。

图片银行流程：

```text
点击图片槽位
→ 选择图片银行（速卖通）
→ 按规则找图
→ 选择图片
→ 确认
→ 校验回填
```

失败策略：重试一次，切换图片空间，仍失败则进入异常池。

### 13.10 阶段 J：填写详情与合规字段

目标：填写 PC 详情、无线详情、海关属性、欧盟负责人、制造商、标签图。

规则：无真实配置时停止，不自动编造欧盟责任人、制造商或证书。

### 13.11 阶段 K：启用半托管

目标：在普通编辑页勾选半托管参与，并进入半托管编辑页。

步骤：

1. 定位其他信息。
2. 找到半托管服务。
3. 勾选参与。
4. 等待编辑半托管信息按钮出现。
5. 点击编辑半托管信息。
6. 若有校验错误，停止。
7. 成功进入半托管编辑页。

### 13.12 阶段 L：填写半托管国家

目标：按半托管模板确认参加国家。

策略：全选、指定国家、页面禁用时沿用默认并记录。

### 13.13 阶段 M：填写半托管货品信息

目标：填写是否原箱、物流属性、重量、尺寸。

默认值：

```text
是否原箱：否
物流属性：普货
重量：0.03
尺寸：10 x 10 x 2
```

### 13.14 阶段 N：填写半托管变种信息

目标：填写价格、SKU、货品编码、货品条码、JIT 库存。

规则：

- 价格为空且无计价配置，停止。
- SKU 缺失或重复，按规则修正或停止。
- 货品编码默认等于 SKU。
- 货品条码按配置留空或填写。
- JIT 库存默认 100。

### 13.15 阶段 O：保存半托管信息

目标：只点击保存，不发布，并校验保存成功。

步骤：

1. 定位保存按钮。
2. 确认立即发布未被选中、未被点击。
3. 点击保存。
4. 监听接口返回。
5. 读取页面提示。
6. 记录保存结果。

成功信号示例：

```json
{
  "code": 0,
  "msg": "产品已保存到「待发布」"
}
```

页面提示示例：您的产品编辑成功。

## 20. 权限与安全

### 20.1 登录安全

- 不收集店小秘账号密码。
- 用户在真实浏览器输入账号密码。
- 本地保存浏览器登录态。
- 登录失效时进入人工接管。

### 20.2 操作安全

系统必须阻止：

- 操作非当前任务商品。
- 未领取商品直接编辑。
- 归属不明商品继续编辑。
- 点击发布按钮。
- 出现发布弹窗后继续执行。
- 无依据填写合规字段。

### 20.3 发布隔离

前端不提供发布按钮。后端执行器维护 forbidden_buttons 列表。发现发布按钮弹窗即停止。保存前再次检测立即发布未触发。

### 21.1 技术栈

后端：Python、FastAPI、SQLite、Playwright、WebSocket。

前端：React、Vite、TypeScript、Electron。

### 21.2 执行器分层

```text

```

### 21.3 Playwright 策略

定位优先级：

1. URL。
2. 页面标题。
3. 文本。
4. label。
5. 表头 + 行名。
6. DOM class。
7. bounding box。
8. 截图识别。

DOM 定位用于主操作，网络接口返回用于保存确认，截图用于审计、异常分析和人工复核，坐标只作为兜底。

### 21.4 AI 的位置

AI 只用于：

- 生成配置建议。
- 生成标题模板。
- 生成详情页文案草稿。
- 分析异常日志。
- 总结失败原因。
- 帮用户设计规则。

AI 不用于：

- 临场决定类目。
- 临场决定品牌。
- 临场决定是否发布。
- 伪造条码。
- 忽略页面错误。

## 26. 关于全托管的产品判断

全托管不要放进 V1.0。

原因：

- 当前完整真实流程主要覆盖半托管保存主流程。
- 全托管页面、字段、按钮、保存逻辑、发布风险还没有同等完整的流程证据。
- 如果把全托管和半托管混在一个 MVP 里，会拖慢半托管闭环上线。
- 全托管应作为独立状态机分支。

建议架构：

```text
BaseDxmExecutor
├── SmtSemiManagedFlow
└── SmtFullManagedFlow
```

V1.0 只实现 SmtSemiManagedFlow。V1.1 再实现 SmtFullManagedFlow。

## 27. 最终产品定义

用户先在配置中心配置店铺、商品、类目、标题、SKU、价格、库存、物流、图片、合规和半托管规则；系统在真实店小秘页面中按状态机执行领取、备注、编辑、半托管填写和保存；每一步校验 DOM、页面提示、接口返回和截图证据；任何归属不明、字段缺失、发布风险、页面异常都进入异常池；最终只保存到待发布，并生成可复核报告。
