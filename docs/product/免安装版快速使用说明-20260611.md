# DXM Agent Console 免安装版快速使用说明 - 2026-06-11

## 适用范围

此免安装版用于真实店小秘半托管自动化的受控流程：打开真实店小秘浏览器、补齐编辑页配置、完成只读页面检查、人工确认后执行单商品只保存。

当前只放行受控单商品只保存。批量、无人值守和发布入口仍保持关闭。

## 启动

1. 首选双击桌面目录免安装版 `C:\Users\wz\Desktop\DXM-Agent-Console-免安装版\DXM-Agent-Console.exe`。
2. 如果从仓库运行，双击 `outputs\desktop-build\win-unpacked\DXM-Agent-Console.exe`。
3. 首次启动会启动本机 Python 后端和前端资源；等待工作台出现“继续下一步”。

不要单独启动后端或前端窗口。桌面版会在一个 Agent 控制台窗口内管理本机服务。

使用目录版时必须保留整个文件夹和 `resources` 目录，不能只复制 exe 文件。single-file portable 当前未通过本机 smoke，不作为交付入口。

## 推荐操作顺序

1. 进入“操作引导”。
2. 按“现在只做这一步”完成真实店小秘登录。
3. 进入“编辑页配置”，按店小秘编辑页分区填写本次任务的真实取值。
4. 进入“当前任务”，创建或选择单商品只保存任务。
5. 运行只读页面检查。检查未通过时不要启动保存。
6. 人工确认后启动单商品只保存。
7. 进入“执行控制台”观察真实浏览器、实时日志和当前步骤。
8. 完成后进入“报告中心”和“证据中心”核对保存成功、未发布证明和网络保存回包。

## 关键边界

- 可以做：真实登录、配置、只读检查、受控单商品只保存、报告复核。
- 不可以做：批量保存、无人值守写入、发布、保存并发布、移入待发布。
- 如果页面提示当前任务不存在，请到“当前任务”重新选择或创建单商品只保存任务。
- 如果提示工作台服务异常，请先看“执行控制台”的运行日志。
